# Earth exploration and image lab

30 September 2026. Scoped extension to the existing slate/teal interface. The explicit request for an animated Earth permits decorative motion on this page; it does not change the no-fabricated-live-status rule in MASTER.md.

UI UX Pro Max search: `weather globe exploration dark --design-system`. Its immersive dark/precision typography fits; its light-sky card background does not fit the requested orbital view. Use a navy canvas, restrained cyan markers and high-contrast opaque text panels. Keep system fonts and native controls. The Three.js stack search selected reactive reduced-motion handling.

- Earth is a geography explorer, separate from observed radar and model results.
- Search supports only the bundled named cities and discloses that limit.
- Cloud motion and lighting are illustrations. Static NASA imagery has credits/hash beside the asset.
- Camera focus and zoom interpolate to actual latitude/longitude; reduced motion sets the destination immediately.
- Pause control, hidden-tab/offscreen suspension, render-on-demand when paused, disposable GPU resources.
- Non-WebGL fallback keeps the map, selected coordinates and all onward actions.
- Image lab shows selected processing beside original observations, with future truth labelled separately.
- Source collection remains in the existing research route, preserving its research document links.
