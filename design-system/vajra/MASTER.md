# VAJRA interface decisions

Updated 30 September 2026 using ui-ux-pro-max design-system and React searches.

The accessible government-service recommendation fits. The generated sales funnel,
red brand palette and decorative Calistoga heading font do not fit a research console.
Use a restrained slate/teal system, with amber reserved for a limitation and red for an error.

- Desktop: persistent navigation, generous reading area, map and observation health together.
- Mobile: collapsed navigation, 44 px controls, single-column public brief, safe-area padding.
- Plain explanations first; detailed algorithms belong in the guide and officer evidence.
- Overview, officer workbench, public preview, and guide are distinct URL-addressable views.
- Native links, buttons and selects; visible keyboard focus and a skip link.
- System fonts; no external font dependency. Body text 16 px, supporting text 14 px.
- No decorative motion, no fabricated live status, no universal all-clear.
- App shell is available offline after caching. Forecast API responses are never cached by the service worker.
- Public content is a labelled layout preview or an explicitly saved historical simulation.
- Responsive validation at 375, 768 and 1440 px, landscape, enlarged text and reduced motion.
- These are presentation views, not authentication or authorisation boundaries.
